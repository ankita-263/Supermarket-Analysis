# 🛒 Supermarket Sales Analysis

## 📌 Project Overview
This project analyzes supermarket sales data to understand customer behavior, product performance, and revenue trends using SQL, Excel, and Power BI.

## 🎯 Objective
- Identify top-performing product categories
- Analyze sales trends by branch and city
- Understand customer purchasing patterns

## 🛠 Tools & Technologies
- SQL
- Microsoft Excel
- Power BI

## 📊 Analysis Performed
- Data cleaning and preprocessing using Excel
- Data exploration using SQL queries
- Sales trend and KPI analysis
- Interactive dashboard creation in Power BI

## 🔍 Key Insights
- Food & Beverage category generated highest revenue
- Peak sales observed during evening hours
- Branch-wise performance differences identified
